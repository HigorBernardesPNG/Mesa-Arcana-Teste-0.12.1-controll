# 031 — Congelamento do escopo do MVP

## Decisão
A partir do MVP 0.1 RC1, o escopo funcional é congelado até a realização de uma sessão real completa.

## Motivo
A plataforma já possui o núcleo necessário para uso real. Acrescentar funcionalidades antes de observar o produto em mesa aumentaria risco de regressão e atrasaria a validação.

## Regra
Durante o ciclo RC entram apenas correções de bug, estabilidade, persistência, compatibilidade, segurança de dados e problemas graves de usabilidade.

## Pós-MVP
Música, atualização, distribuição pública, controle de uso/licenciamento, hub, polimento visual final e demais evoluções ficam no backlog.
