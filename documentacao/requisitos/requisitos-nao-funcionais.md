# Requisitos não funcionais

- Funcionamento prioritário em rede local.
- Jogadores sem necessidade de instalação.
- Código legível e modular.
- Nomes do domínio em português.
- Tipagem estrita em TypeScript.
- Dados externos validados antes de uso.
- Campanhas portáveis entre computadores.
- Recuperação do estado após reconexão.
- Interface responsiva o suficiente para desktop e notebook; suporte móvel será evoluído depois.


## Interface e usabilidade

- A identidade visual do produto é Mesa Arcana.
- A interface deve preservar hierarquia clara, mapa como foco e consistência entre Mestre, Jogador e Entrada.
- Painéis devem suportar conteúdo excedente por scroll sem empurrar o mapa ou quebrar o layout.
- O refinamento visual não pode reduzir permissões, ocultar controles necessários ou introduzir funcionalidades inexistentes.
- O layout deve continuar utilizável em desktop e celular.
