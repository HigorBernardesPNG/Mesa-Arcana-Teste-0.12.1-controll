# Próximos passos

## MVP 0.1 — Release Candidate

1. Executar `npm run validar:mvp`.
2. Testar o aplicativo do Mestre em Windows.
3. Executar o Diagnóstico e guardar um relatório JSON de referência.
4. Testar em outro computador sem ambiente de desenvolvimento, quando possível.
5. Realizar uma sessão real completa usando `documentacao/mvp/checklist-sessao-real.md`.
6. Corrigir apenas falhas bloqueadoras/regressões antes de adicionar novos recursos.
7. Promover a RC para MVP 0.1 quando os critérios de release forem satisfeitos.

## Pós-MVP
- estratégia simples de distribuição e atualização;
- versão Preview/controle de uso, caso ainda seja desejável;
- música/ambientação local controlada pelo Mestre;
- polimento fino de UI/UX;
- página hub pública;
- outras melhorias surgidas do uso real.

Paredes/cobertura permanecem deliberadamente na interpretação da mesa.
