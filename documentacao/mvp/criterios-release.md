# Critérios para promover RC a MVP 0.1

A Release Candidate pode ser promovida quando:

- uma sessão real completa for realizada sem falha bloqueadora;
- não houver perda ou corrupção de campanha;
- entrada/reconexão de jogadores funcionar de forma previsível;
- os principais recursos visuais permanecerem sincronizados;
- diagnóstico não indicar falha estrutural;
- problemas encontrados forem classificados e os bloqueadores corrigidos.

Melhorias cosméticas e recursos novos não impedem a promoção, salvo quando prejudicam seriamente o uso.
